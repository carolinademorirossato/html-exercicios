# 🌐 Exercícios de HTML

Repositório destinado aos exercícios e exemplos desenvolvidos durante meus estudos de **HTML**.

O objetivo deste repositório é registrar minha prática e evolução nos fundamentos do desenvolvimento web, reunindo atividades realizadas durante cursos e estudos.

---

## 📚 Conteúdos praticados

Durante os exercícios foram trabalhados conceitos como:

- Estrutura básica de páginas HTML
- Tags e elementos HTML
- Títulos e parágrafos
- Listas
- Links e hiperlinks
- Navegação entre páginas
- Bookmarks e âncoras
- Organização básica de documentos HTML

---

## 📂 Exercícios

O repositório contém diferentes arquivos desenvolvidos durante os estudos:

- `firstPage.html` — primeiros exemplos de estrutura HTML
- `secondPage.html` — prática com múltiplas páginas
- `hiperlink.html` — utilização de links e navegação
- `bookmark.html` — utilização de bookmarks e âncoras
- `lista.html` — prática com listas HTML

---

## 🛠️ Tecnologia

- HTML5
